# Tutor de Análisis Crítico de Lectura 📚

Este proyecto forma parte de una investigación orientada al fortalecimiento del pensamiento crítico en estudiantes de urbanismo y planeación territorial.

## 🎯 Objetivo
Facilitar un diálogo socrático entre el estudiante y una Inteligencia Artificial (Gemini 2.5 Flash) basado estrictamente en lecturas obligatorias de los cursos.

## 📂 Estructura Académica
El tutor está configurado para tres asignaturas específicas:
* **POT:** Análisis de planes de ordenamiento y sesiones de normativa.
* **Urb_Historia_1:** Evolución histórica del urbanismo.
* **Urb_Historia_2:** Historia urbana contemporánea.

## 🚀 Instrucciones para Estudiantes
1. Accede a la URL de la aplicación en Streamlit.
2. Selecciona tu **Curso**, **Actividad** y **Sesión**.
3. Realiza la lectura del PDF correspondiente.
4. Interactúa con el tutor hasta obtener tu **Código de Validación**.
5. Descarga el reporte y súbelo a Moodle.

## 🛠️ Tecnologías utilizadas
* **Python** (Lenguaje principal)
* **Streamlit** (Interfaz web)
* **Google Gemini API** (Modelo de lenguaje)
